High-frequency trading requires not only accurate decisions but predictable, ultra-low latency, which general-purpose CPUs cannot guarantee under scheduling and memory-hierarchy jitter. This work presents an Ethernet-enabled, customizable neural-inference framework embedded entirely in the programmable logic of a low-cost Xilinx Zynq-7000 SoC. The processing system handles packet reception and control; a hardware multi-layer perceptron (40-64-32-16-3) performs inference in the fabric. Feature vectors are streamed over AXI-DMA / AXI-Stream and the model is deployed in Q8.8 fixed point, so a Python-trained network is re-embedded without redesigning the datapath. The design uses 87.3 % of the DSP slices and 27.0 % of the LUTs at an estimated 2.70 W, closes timing at 125 MHz, and completes an inference in 768 ns. A cycle counter read back after every inference shows this latency to be invariant: over 100000 inferences the standard deviation is zero. The same network run bare-metal on the SoC’s own Cortex-A9 at -O3 requires 52.4 µs, so the fabric path is 68 times faster and, unlike the processor, has no spread at all. Because the feature set, network shape, fixed-point format and decision classes are configurable, the system is a reusable FPGA-embedded inference framework, demonstrated on an HFT decision task.
